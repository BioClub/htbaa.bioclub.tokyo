# HTBAA - How to Biomanufacture Almost Anything @BioClub Tokyo

Documention site for HTBAA@BioClub: https://htbaa.bioclub.tokyo

## Hugo

#### Start hugo server

`hugo server`

#### Render site

`hugo`

#### Content

Content lives in the `content` directory

#### Upgrade to latest version of Hugo

`brew upgrade hugo`
